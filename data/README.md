# Engineering Knowledge Intelligence — RAG Dataset

Synthetic engineering knowledge base for the M8 RAG & Memory project.

Contains mixed Markdown/TXT/PDF sources, document metadata, version conflicts, operational procedures,
incidents, API documentation, architecture decisions, policies, and 30 labeled evaluation questions.

Designed for:
S1 ingestion + baseline RAG
S2 chunking + retrieval
S3 hybrid + reranking
S4 memory + RAG
S5 failure analysis + evaluation
S6 production optimization + security
